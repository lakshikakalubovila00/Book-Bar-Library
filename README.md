Book Bar Library Management System

A web-based Library Management System developed to streamline and automate library operations, including member management, book management, borrowing and reservations, supplier management, purchasing, donations, reporting, and role-based access control.

✨ Key Features

👥 Member Management, Guarantor Management, Memberships Management, Member Payment Management
📚 Books & Book Copies Management
🔄 Book Reservations, Book Borrowing, Book Renewal, Book Handover and Fine Management
🔎 Online Public Access Catalogue (OPAC)
🏢 Supplier Management
🛒 Purchasing, Goods Received Notes (GRN), Supplier Payment Management
🎁 Donator & Donation Management
📊 Reports
🔐 Authentication & Role-Based Access Control

🛠️ Technologies Used

- Backend: Java 21, Spring Framework, Spring Boot
- Frontend: HTML5, CSS3, JavaScript, Bootstrap 5, jQuery
- Database: MySQL 8.0
- Build Tool: Gradle
- Development: IntelliJ IDEA
- Design & Modeling: Figma, Visual Paradigm
- Version Control: Git & GitHub
